<!-- ABOUT THE PROJECT -->

This cuisine-themed website features a diverse collection of meals, ingredients, and preparation methods from diverse cultures worldwide. As a user, you can explore, search, and filter recipes by ingredients, meal name, and region preferences.. built with React Js, JavaScript, and Redux.

**Core Functionalities:**
* Displays meals by category.
* Search meals by ingredients.
* View meals based in different areas/locations.
* Get information on all meal preparation processes.

I had a great time building this project and sincerely love it... I hope you do too, Click [Here](https://paradise-cuisine.netlify.app/) to view the project live!

<!-- GETTING STARTED -->
## Getting Started

### Clone-Locally
- Enter this url: [https://github.com/Carshy/paradise-cuisine](https://github.com/Carshy/paradise-cuisine) in your web browser.
- Once opened navigate to the top left level of the project a green code download button will be visible on the righthand side.
- Select download Zip option from drop down menu.
- Once the download is complete you will be able to access my project locally . 

### Prerequisites
* npm
  ```sh
  npm install npm@latest -g
  ```

### Start-local-server
```sh
cd paradise-cuisine

npm i

npm start
```
